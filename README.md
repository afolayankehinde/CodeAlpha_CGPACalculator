# CGPA Calculator

A C++ program that calculates a student's GPA for each semester
and the overall CGPA across all semesters.

## What it does
- Asks for the number of semesters and courses
- Takes the grade and credit hours for each course
- Shows each course, the GPA for every semester, and the final CGPA
- Handles the case where zero credit hours are entered

## How to run
```
g++ cgpa2.cpp -o cgpa2
./cgpa2
```
